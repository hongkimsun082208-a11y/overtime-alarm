# 시간외 알리미 (갤럭시용)

시간외 근무 중에 매시간 "확인" 누르는 걸 깜빡하지 않도록 폰이 챙겨 주고,
이번 달 쌓인 시간외를 대신 세어 주는 앱입니다.

## 어떻게 동작하나요

### 평일

- **17:50** 에 폰이 한 번 물어봅니다. `오늘 시간외 근무 해요? [예] / [아니오]`
  **공휴일에는 묻지 않습니다.** (공휴일 표가 들어 있습니다)
- `[예]` 를 누르면 19:30 부터 1시간마다 **진동으로** 알려 줍니다.
- 알림이 오면 업무 시스템에서 확인을 누르고, 알림의 `[확인했어요]` 를 누릅니다.
  누른 시각 기준으로 다음 알림을 다시 셉니다. (19:35 에 눌렀으면 다음은 20:35)
- 안 누르면 **3분 뒤에 한 번 더** 진동합니다. 그래도 반응이 없으면
  **퇴근한 것으로 보고 그날을 종료**합니다. 빈 사무실에 계속 울리지 않습니다.
- 22:00 이 되면 자동으로 종료됩니다.

### 주말·공휴일

묻지 않습니다. 할 때만 직접 켭니다.

- 상단바를 내려 **[시간외]** 타일을 한 번 누르거나
- 앱에서 `[지금 시작]`

### 상시 알림

근무 중에는 알림창에 조용히 한 줄이 남아 있습니다.

```
시간외 근무 중 · 오늘 2시간 30분
다음 확인 오후 9:30 · 오후 10:00 자동 종료
[확인했어요] [30분 미루기] [오늘 종료]
```

알림이 울릴 때까지 기다리지 않고 미리 눌러도 됩니다.

## 시간 계산

| 구분 | 세는 방법 | 하루 한도 |
| --- | --- | --- |
| 평일 | 18:00 부터, **석식 1시간 공제** | 4시간 |
| 주말·공휴일 | 시작한 시각부터 (공제 없음) | 8시간 |

- 월 한도는 **35시간**. 90% 를 넘기면 알림에 경고가 붙습니다.
- 예) 평일 18:00 ~ 22:00 근무 → 4시간 − 석식 1시간 = **3시간**
- 모든 값(기산 시각·석식 공제·하루 한도·월 한도)은 앱에서 바꿀 수 있습니다.
- `[이번 달 기록 보기]` 에서 날짜를 누르면 그날 시간을 직접 고칠 수 있습니다.

> 여기 쌓이는 숫자는 참고용입니다. 공식 기록은 업무 시스템 기준입니다.

## 공휴일

2026 ~ 2027년 관공서 공휴일이 들어 있습니다. (근로자의 날은 공무원 휴일이 아니라 제외)
표에 없는 해이거나 임시공휴일이 생기면, 앱의 **[오늘을 휴일로 계산]** 스위치로 그날만 바꾸면 됩니다.

## APK 만들기 (사무실 PC에 아무것도 깔지 않습니다)

GitHub 가 코드를 받아 APK 를 만들어 주고, 폰이 그 APK 를 직접 내려받습니다.
**드래그는 쓰지 않습니다.** 파일 선택 1번, 붙여넣기 1번입니다.

### 1단계 — 소스 압축파일 올리기

저장소에서 `Add file ▾` → `Upload files` → 파란 글씨 **choose your files** 클릭 →
`app-src.zip` 선택 → 맨 아래 `Commit changes`

### 2단계 — 빌드 설정 만들기

`Add file ▾` → `Create new file` → 이름 칸에 아래를 그대로 입력
(`/` 를 칠 때마다 폴더가 자동으로 만들어집니다)

```
.github/workflows/build.yml
```

내용 칸에 `깃헙에_붙여넣기.yml` 의 내용을 붙여넣고 `Commit changes`

### 3단계 — 기다리기

커밋하는 순간 `Actions` 탭에서 빌드가 시작됩니다. 3~5분.
초록 ✓ 가 되면 끝입니다. (빨간 ✗ 면 그 화면을 캡처해서 보내 주세요)

### 4단계 — 폰에 설치

폰 크롬으로 `https://github.com/<내아이디>/overtime-alarm/releases/latest` 접속 →
`Assets` 의 `overtime-alarm.apk` 를 누릅니다.

- "이런 유형의 파일은 기기에 손상을 줄 수 있습니다" → 계속
- "이 출처의 앱 설치 차단" → 설정 → 크롬에 설치 허용 → 뒤로 → 설치

설치 후 앱을 열고

1. 알림 권한 허용
2. `[배터리 절전 예외로 두기]` 눌러 허용
3. `[진동 테스트]` 눌러 확인

## 갤럭시에서 확실히 받으려면 (한 번만)

갤럭시는 안 쓰는 앱을 절전 상태로 돌려서 알림을 늦추는 일이 있습니다.

1. 앱의 `[배터리 절전 예외로 두기]` → 허용
2. 설정 → 배터리 → 백그라운드 사용 제한 → **절전 모드 앱** 에 이 앱이 있으면 제거

알림은 시계 앱과 같은 등급(`setAlarmClock`)으로 걸려 있어서, 위 두 가지만 해 두면
절전 모드에서도 제시간에 옵니다.

## 나중에 고칠 때

소스를 고쳐 `app-src.zip` 을 다시 만들어 같은 자리에 덮어 올리면,
Actions 가 새 APK 를 만듭니다. 폰에서 `releases/latest` 에서 받아 덮어 설치하면 됩니다.
