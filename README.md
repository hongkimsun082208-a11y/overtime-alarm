# 시간외 확인 알람 (갤럭시용)

시간외 근무 중에 매시간 "확인" 누르는 걸 깜빡하지 않도록 폰이 챙겨 주는 앱입니다.

## 어떻게 동작하나요

1. **평일 저녁 6시** — 폰이 한 번 물어봅니다. `오늘 시간외 근무 해요?` **[예] / [아니오]**
2. **[예]** 를 누르면 → **19:30, 20:30, 21:30 …** 매시간 알람이 울립니다.
3. 알람이 울리면 업무 시스템에서 확인을 누르고, 알림의 **[확인했어요]** 를 누릅니다.
4. 안 누르면 **5분마다 계속** 다시 울립니다. (놓칠 수가 없어요)
5. **23:00** 이 되면 자동으로 종료됩니다. 중간에 끝내려면 **[오늘 종료]**.
6. **[아니오]** 를 누르거나 그냥 두면 그날은 조용합니다.

위치나 와이파이를 보지 않으므로 **어디에 있든** 똑같이 동작합니다.

앱 안에서 바꿀 수 있는 것: 질문 시각 · 첫 확인 시각 · 확인 간격(30/60/90/120분) ·
자동 종료 시각 · 다시 알림 간격(2/3/5/10분) · 평일만 여부.
`지금 시작` 버튼으로 저녁 질문을 기다리지 않고 바로 켤 수도 있습니다.

## 설치 방법 (사무실 PC에 아무것도 깔지 않습니다)

GitHub 가 코드를 받아 APK 를 만들어 주고, 폰이 그 APK 를 직접 내려받습니다.

### 1단계 — GitHub 저장소 만들기

1. <https://github.com> 로그인 → 오른쪽 위 **+** → **New repository**
2. Repository name: `overtime-alarm`
3. **Public** 으로 둡니다.
   (Private 로 하면 폰 브라우저에서도 GitHub 로그인을 해야 APK 를 받을 수 있어 번거롭습니다.
   이 앱 코드는 민감한 내용이 없습니다.)
4. **Create repository**

### 2단계 — 파일 올리기

1. 만들어진 저장소 화면에서 **uploading an existing file** 링크를 누릅니다.
2. 탐색기에서 `overtime-alarm` 폴더를 **열고**, 그 **안에 있는 것 전부**를 선택해서
   (`Ctrl + A`) 브라우저 창에 끌어다 놓습니다.

   > ⚠️ `overtime-alarm` **폴더 자체를** 끌어다 놓으면 안 됩니다.
   > 폴더 안의 내용물이 저장소 맨 위에 와야 합니다.
   >
   > 올린 뒤 저장소 첫 화면에 `app`, `.github`, `build.gradle.kts`,
   > `settings.gradle.kts`, `gradle.properties` 가 보이면 맞습니다.

3. 아래 **Commit changes** 를 누릅니다.

### 3단계 — APK 가 만들어지기를 기다리기

1. 저장소 위쪽 **Actions** 탭을 누릅니다.
2. `APK 만들기` 가 돌아가고 있습니다. **3~5분** 걸립니다.
3. 초록색 ✓ 가 되면 끝입니다. (빨간 ✗ 가 나오면 그 화면을 캡처해서 보내 주세요)

### 4단계 — 폰에 설치하기

1. **폰 크롬**으로 이 주소를 엽니다 (`내아이디` 는 본인 GitHub 아이디):

   ```
   https://github.com/내아이디/overtime-alarm/releases/latest
   ```

2. 아래 **Assets** 의 `overtime-alarm.apk` 를 누릅니다.
3. "이런 유형의 파일은 기기에 손상을 줄 수 있습니다" → **계속**
4. 다운로드된 파일을 눌러 설치합니다.
   "이 출처의 앱 설치 차단" 이 나오면 → **설정** → **크롬**에 설치 허용 → 뒤로 → 설치
5. 설치 후 앱을 열고
   - 알림 권한 **허용**
   - **배터리 절전 예외로 두기** 눌러 **허용**
   - **알람 테스트** 눌러서 소리·진동 확인

### 나중에 고칠 때

코드를 고쳐 다시 올리면(같은 파일을 덮어쓰기) Actions 가 새 APK 를 만들고,
위 `releases/latest` 주소에서 새로 받아 덮어 설치하면 됩니다.

## 갤럭시에서 알람을 확실히 받으려면 (한 번만)

갤럭시는 안 쓰는 앱을 절전 상태로 돌려서 알람을 늦추는 일이 있습니다.
앱 안의 버튼으로 1번은 바로 되고, 2번은 직접 한 번 해 두세요.

1. **배터리 절전 예외** — 앱 안의 `배터리 절전 예외로 두기` 버튼 → 허용
2. **설정 → 배터리 → 백그라운드 사용 제한 → 절전 모드 앱** 에 이 앱이 있으면 **제거**

알람은 시계 앱과 같은 등급(`setAlarmClock`)으로 걸려 있어서,
위 두 가지만 해 두면 절전 모드에서도 제시간에 울립니다.
